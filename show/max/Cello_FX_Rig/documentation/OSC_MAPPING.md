# OSC mapping

OSC is currently **not implemented** in this flat patch. The earlier `oscparse` object was absent from the installed Max 9.1.5 reference/help tree and was removed to avoid leaving an unresolved object in the project. No OSC port is active. A native decoder or a verified native Max OSC parsing route is still needed before TouchDesigner or TouchOSC can control the patch.

Planned namespace: `/cello/sustain/on`, `/cello/sustain/mix`, `/cello/whammy/pitch`, `/cello/delay/time`, `/cello/delay/feedback`, `/cello/reverb/size`, `/cello/reverb/mix`, `/cello/master/volume`.
