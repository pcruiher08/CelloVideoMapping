# MIDI CC mapping

The flat patch uses native `ctlin` objects for these direct controls. MIDI interface input is selected in Max MIDI settings. Hardware control has not yet been tested.

| CC | Parameter |
|---:|---|
| 21 | Whammy expression |
| 22 | Delay feedback (clamped to 0–0.9) |
| 23 | Delay time in ms |
| 24 | Reverb wet mix |
| 7 | Master level |

Sustain activation and module bypass MIDI mappings are not implemented.
